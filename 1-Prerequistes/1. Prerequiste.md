# As Best Practice should create a VM as a "Client VM" to manage from it the infrastructure and install management tools on it like:
-> Windows Admin Center:
To manage servers, Hyper-V, storage, and networks from the browser. Very compatible with Server Core.

-> Failover Cluster Manager:
To manage Nodes, Roles, CSVs, Quorum, and Failover. You can install it on a management device.

-> Hyper-V Manager:
To create and manage VMs, Virtual Switches, and Integration Services.

-> SCVMM Console:
To manage Fabric, Clusters, VM Templates, Logical Networks, and SDN, after installing VMM.
