# 6.1 SQL01 – SQL Server for VMM (HA VM on CSV)

> Replaces the SQL parts of `6. SCVMM.md` and `Efada.md`.
> Supported by VMM 2025: SQL Server **2019 / 2022 / 2025**, Standard or Enterprise, 64-bit. This file uses **SQL Server 2022 Standard**.

## 1. VM (on HV01): OS + data + log disks

```powershell
. C:\ClusterStorage\CSV01\_Base\Build\New-InfraVM.ps1
$csv = "C:\ClusterStorage\CSV01"
New-InfraVM -Name SQL01 -vCPU 4 -RAM 16GB -OSDiskSize 100GB -Path $csv -BaseVhdx "$csv\_Base\WS2025-STD-DE.vhdx" -Vlan 100
Set-VM -Name SQL01 -AutomaticStartAction Nothing

# Data and log disks (fixed size is recommended for SQL)
New-VHD -Path "$csv\SQL01\Virtual Hard Disks\SQL01-Data.vhdx" -SizeBytes 150GB -Fixed | Out-Null
New-VHD -Path "$csv\SQL01\Virtual Hard Disks\SQL01-Log.vhdx"  -SizeBytes 50GB  -Fixed | Out-Null
Add-VMHardDiskDrive -VMName SQL01 -Path "$csv\SQL01\Virtual Hard Disks\SQL01-Data.vhdx"
Add-VMHardDiskDrive -VMName SQL01 -Path "$csv\SQL01\Virtual Hard Disks\SQL01-Log.vhdx"

# SQL ISO in the DVD drive (copy the ISO to the CSV first)
Add-VMDvdDrive -VMName SQL01 -Path "$csv\_Base\ISO\SQLServer2022-x64-ENU.iso"

Add-ClusterVirtualMachineRole -VMName SQL01
(Get-ClusterGroup SQL01).Priority = 3000      # High: start before VMM after a cluster restart
Start-ClusterGroup SQL01

$local = Get-Credential -UserName "Administrator"
$dom   = Get-Credential -UserName "ETISALAT\Administrator"
Wait-VMReady -Name SQL01 -Credential $local
Expand-GuestC -Name SQL01 -Credential $local

Invoke-Command -VMName SQL01 -Credential $local -ScriptBlock {
    Rename-NetAdapter -Name (Get-NetAdapter | Select-Object -First 1).Name -NewName "Management"
    New-NetIPAddress -InterfaceAlias "Management" -IPAddress 10.10.100.31 -PrefixLength 24 -DefaultGateway 10.10.100.1
    Set-DnsClientServerAddress -InterfaceAlias "Management" -ServerAddresses 10.10.100.21, 10.10.100.22
    Add-Computer -DomainName etisalat.local -NewName SQL01 -OUPath "OU=Management Servers,OU=Infrastructure,DC=etisalat,DC=local" -Credential $using:dom -Restart
}
Wait-VMReady -Name SQL01 -Credential $dom
```

## 2. Disks inside SQL01 (64K NTFS)

```powershell
Invoke-Command -VMName SQL01 -Credential $dom -ScriptBlock {
    $raw = Get-Disk | Where-Object PartitionStyle -eq 'RAW' | Sort-Object Number
    $raw[0] | Initialize-Disk -PartitionStyle GPT -PassThru | New-Partition -DriveLetter D -UseMaximumSize |
        Format-Volume -FileSystem NTFS -AllocationUnitSize 65536 -NewFileSystemLabel "SQLData" -Confirm:$false
    $raw[1] | Initialize-Disk -PartitionStyle GPT -PassThru | New-Partition -DriveLetter E -UseMaximumSize |
        Format-Volume -FileSystem NTFS -AllocationUnitSize 65536 -NewFileSystemLabel "SQLLog" -Confirm:$false
    Get-Volume | Where-Object DriveLetter | Format-Table DriveLetter, FileSystemLabel, Size
}
```

## 3. Install SQL Server 2022 unattended (inside SQL01)

Run in an RDP session on SQL01 as `ETISALAT\Administrator` (or via `Invoke-Command -VMName SQL01 -Credential $dom`):

```powershell
$media = (Get-Volume | Where-Object DriveType -eq 'CD-ROM').DriveLetter
New-Item -ItemType Directory -Path D:\SQL\Data, D:\SQL\TempDB, E:\SQL\Log -Force | Out-Null

& "$($media):\setup.exe" /Q /ACTION=Install /IACCEPTSQLSERVERLICENSETERMS /UPDATEENABLED=False `
    /FEATURES=SQLENGINE /INSTANCENAME=MSSQLSERVER `
    /SQLSYSADMINACCOUNTS="ETISALAT\GG-SQL-Admins" "ETISALAT\Administrator" `
    /SQLCOLLATION=SQL_Latin1_General_CP1_CI_AS `
    /SQLSVCSTARTUPTYPE=Automatic /AGTSVCSTARTUPTYPE=Automatic `
    /INSTALLSQLDATADIR="D:\SQL" /SQLUSERDBDIR="D:\SQL\Data" /SQLUSERDBLOGDIR="E:\SQL\Log" `
    /SQLTEMPDBDIR="D:\SQL\TempDB" /SQLTEMPDBLOGDIR="E:\SQL\Log" /SQLTEMPDBFILECOUNT=4 `
    /USESQLRECOMMENDEDMEMORYLIMITS /TCPENABLED=1
# Add /PID="XXXXX-XXXXX-XXXXX-XXXXX-XXXXX" if your media doesn't embed the product key.

Get-Content "C:\Program Files\Microsoft SQL Server\160\Setup Bootstrap\Log\Summary.txt" -TotalCount 20
```

Notes:
- The service accounts are the default virtual accounts (`NT Service\MSSQLSERVER`). SQL registers its own SPN on the `SQL01` computer account, so no SPN work is needed.
- If you later move to **Always On** (2 SQL nodes), you'll need a domain account or gMSA for the SQL service. VMM must be installed against a database that is **not** in an AG yet; you add it to the AG after VMM is installed.

## 4. Firewall + patch

```powershell
New-NetFirewallRule -DisplayName "SQL Server TCP 1433" -Direction Inbound -Protocol TCP -LocalPort 1433 -Action Allow -Profile Domain
```

Install the latest **SQL Server 2022 Cumulative Update** (download the CU on MGMT01, copy it, run it quietly with `/quiet /IAcceptSQLServerLicenseTerms /Action=Patch /AllInstances`).

Then eject the ISO (on the host that owns the VM): `Set-VMDvdDrive -VMName SQL01 -Path $null`.

> PowerShell Direct (`-VMName`) only works on the host that **currently runs** the VM. If the VM is running on another node, check with `Get-ClusterGroup SQL01` and run the commands there.
