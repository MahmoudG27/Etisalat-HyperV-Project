# 3.1 Join HV01–HV04 to the domain

> Replaces `3. ThirdStep.md`. Run on **each host** (iLO console or `Enter-PSSession -ComputerName 10.10.100.1x`).

The host IP lives on the host vNIC **`vEthernet (Management)`** (not on a physical NIC). DNS was already set to DC01/DC02 in 1.1. Verify:

```powershell
Get-DnsClientServerAddress -InterfaceAlias "vEthernet (Management)" -AddressFamily IPv4
# If needed:
Set-DnsClientServerAddress -InterfaceAlias "vEthernet (Management)" -ServerAddresses 10.10.100.21, 10.10.100.22
```

Connectivity checks (DC02 doesn't exist yet, so only DC01 answers):

```powershell
Test-NetConnection 10.10.100.21 -Port 389
Resolve-DnsName etisalat.local
nltest /dsgetdc:etisalat.local
```

Join, placing the computer object directly in the right OU:

```powershell
$cred = Get-Credential -UserName "ETISALAT\Administrator" -Message "Domain admin"
Add-Computer -DomainName "etisalat.local" -OUPath "OU=Hyper-V Hosts,OU=Infrastructure,DC=etisalat,DC=local" -Credential $cred -Restart
```

After the reboot, log in as `ETISALAT\Administrator`:

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Name, Domain, PartOfDomain
w32tm /resync
w32tm /query /source      # must show DC01.etisalat.local (domain hierarchy)
```

## Gate 3.1

From DC01 (or any host):

```powershell
Get-ADComputer -Filter 'Name -like "HV0*"' -SearchBase "OU=Hyper-V Hosts,OU=Infrastructure,DC=etisalat,DC=local" | Select-Object Name, Enabled
# Expect HV01, HV02, HV03, HV04
Invoke-Command -ComputerName HV01,HV02,HV03,HV04 -ScriptBlock { "$env:COMPUTERNAME  $(w32tm /query /source)" }
```
