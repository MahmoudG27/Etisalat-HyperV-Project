# 4.1 DC02 – Additional Domain Controller (on HV02 local disk)

> Replaces `4. ADC.md`. Run on **HV02**, logged in as `ETISALAT\Administrator`.

## 1. Bring the helper and base image to HV02

```powershell
Copy-Item \\HV01\C$\Build -Destination C:\ -Recurse -Force
New-Item -ItemType Directory -Path D:\VMs\_Base -Force | Out-Null
Copy-Item \\HV01\D$\VMs\_Base\WS2025-STD-DE.vhdx D:\VMs\_Base\
. C:\Build\New-InfraVM.ps1
```

## 2. Create the VM

```powershell
New-InfraVM -Name DC02 -vCPU 2 -RAM 8GB -OSDiskSize 100GB -Path "D:\VMs" -BaseVhdx "D:\VMs\_Base\WS2025-STD-DE.vhdx" -Vlan 100
Set-VM -Name DC02 -CheckpointType Disabled -AutomaticStartDelay 0
Disable-VMIntegrationService -VMName DC02 -Name "Time Synchronization"
Start-VM DC02

$local = Get-Credential -UserName "Administrator" -Message "Local admin password from 1.2"
$dom   = Get-Credential -UserName "ETISALAT\Administrator" -Message "Domain admin"
Wait-VMReady -Name DC02 -Credential $local
Expand-GuestC -Name DC02 -Credential $local
```

## 3. IP, name

```powershell
Invoke-Command -VMName DC02 -Credential $local -ScriptBlock {
    Rename-NetAdapter -Name (Get-NetAdapter | Select-Object -First 1).Name -NewName "Management"
    New-NetIPAddress -InterfaceAlias "Management" -IPAddress 10.10.100.22 -PrefixLength 24 -DefaultGateway 10.10.100.1
    Set-DnsClientServerAddress -InterfaceAlias "Management" -ServerAddresses 10.10.100.21
    Rename-Computer -NewName DC02 -Restart
}
Wait-VMReady -Name DC02 -Credential $local
```

## 4. Promote to DC

```powershell
$dsrm = Read-Host "DSRM password for DC02" -AsSecureString
Invoke-Command -VMName DC02 -Credential $local -ScriptBlock {
    Resolve-DnsName etisalat.local
    Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
    Install-ADDSDomainController -DomainName "etisalat.local" -InstallDns -SiteName "Cairo-DC" `
        -Credential $using:dom -SafeModeAdministratorPassword $using:dsrm -Force
}
Wait-VMReady -Name DC02 -Credential $dom
```

## 5. Fix DNS client order on both DCs

Each DC points first to the **other** DC, then to itself.

```powershell
Invoke-Command -VMName DC02 -Credential $dom -ScriptBlock {
    Set-DnsClientServerAddress -InterfaceAlias "Management" -ServerAddresses 10.10.100.21, 127.0.0.1
}
# DC01 runs on HV01:
Invoke-Command -ComputerName HV01 -ScriptBlock {
    Invoke-Command -VMName DC01 -Credential $using:dom -ScriptBlock {
        Set-DnsClientServerAddress -InterfaceAlias "Management" -ServerAddresses 10.10.100.22, 127.0.0.1
    }
}
```

> If the nested `Invoke-Command` fails (CredSSP/double hop), run the inner block directly on HV01.

## 6. Health checks

```powershell
Invoke-Command -VMName DC02 -Credential $dom -ScriptBlock {
    Get-ADDomainController -Filter * | Select-Object HostName, IPv4Address, IsGlobalCatalog, Site
    repadmin /replsummary
    repadmin /showrepl
    netdom query fsmo
    Get-SmbShare -Name SYSVOL, NETLOGON
    dcdiag /q
    w32tm /query /source        # must be DC01 (domain hierarchy)
}
```

## FSMO operations (runbook for later)

**Planned maintenance of DC01 (it's online): transfer**

```powershell
Move-ADDirectoryServerOperationMasterRole -Identity "DC02" -OperationMasterRole PDCEmulator, RIDMaster, InfrastructureMaster, SchemaMaster, DomainNamingMaster
```

Then move the **time role** with it:

```powershell
# On DC02 (new PDC)
w32tm /config /manualpeerlist:"0.pool.ntp.org,0x8 1.pool.ntp.org,0x8 time.windows.com,0x8" /syncfromflags:manual /reliable:yes /update
Restart-Service w32time
# On DC01 (old PDC)
w32tm /config /syncfromflags:domhier /reliable:no /update
Restart-Service w32time
```

**DC01 is permanently lost: seize** (only if it will **never** come back)

```powershell
Move-ADDirectoryServerOperationMasterRole -Identity "DC02" -OperationMasterRole PDCEmulator, RIDMaster, InfrastructureMaster, SchemaMaster, DomainNamingMaster -Force
```

After a seize:
1. **Never** power the old DC01 on again on the network.
2. Run metadata cleanup: ADUC → Domain Controllers → delete DC01 → "This DC is permanently offline".
3. Remove its DNS records (A, NS, `_msdcs`).
4. Build a new DC (new name) from 1.2 + this file.
