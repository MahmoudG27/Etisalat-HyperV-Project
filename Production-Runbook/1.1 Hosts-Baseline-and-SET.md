# 1.1 Hosts baseline + SET switch (HV01, HV02, HV03, HV04)

> Replaces `1. FirstStep.md`. Run on **each** host from the **iLO / iDRAC console**. The network changes in this file will drop any RDP/remote session.

## 0. Before installing Windows (hardware checklist)

- [ ] Latest BIOS / firmware / NIC / HBA firmware from the vendor (Dell SUU / HPE SPP / Lenovo XClarity), **identical on all 4 hosts**.
- [ ] BIOS: Virtualization (VT-x / AMD-V) **On**, VT-d / IOMMU **On**, Power profile = **Maximum performance**, Secure Boot **On**, TPM 2.0 **On**.
- [ ] Local RAID volumes: `C:` for the OS (RAID1) and, if present, a second local volume `D:` used only for DC01/DC02 (RAID1/5). If there's no D:, use `C:\VMs` everywhere instead of `D:\VMs`.
- [ ] Write down the MAC address of each port, and which physical switch port it's cabled to (needed for step 2).

## 1. Install the OS

Install **Windows Server 2025 Datacenter (Server Core)**. Datacenter is required for SDN (NC/SLB/GW) and gives unlimited guest licensing.

## 3. Time zone, power plan, rename NICs

```powershell

```

Rename the adapters by MAC. **Replace the MACs** with the real ones from the output above.

```powershell
$map = @{
  "AA-BB-CC-00-00-01" = "NIC1"   # port 1 -> switch A (trunk)
  "AA-BB-CC-00-00-02" = "NIC2"   # port 2 -> switch B (trunk)
  "AA-BB-CC-00-00-03" = "NIC3"   # iSCSI-A
  "AA-BB-CC-00-00-04" = "NIC4"   # iSCSI-B
}
foreach ($mac in $map.Keys) { Get-NetAdapter | Where-Object MacAddress -eq $mac | Rename-NetAdapter -NewName $map[$mac] }

# Disable any unused/onboard ports, so cluster validation doesn't complain about them
Get-NetAdapter | Where-Object { $_.Name -notin "NIC1","NIC2","NIC3","NIC4" } | Disable-NetAdapter -Confirm:$false

Get-NetAdapter | Sort-Object Name | Format-Table Name, InterfaceDescription, MacAddress, LinkSpeed, Status
```

## 5. Jumbo frames on the physical NICs

> Only do this **after** the network team confirms MTU 9216 on all 4 switch ports of this host. Jumbo frames are needed for iSCSI performance and for the HNV/VXLAN overhead.

```powershell
# Check the valid value for your NIC driver (usually 9014, some drivers use 9000)
Get-NetAdapterAdvancedProperty -Name NIC1 -RegistryKeyword "*JumboPacket" | Format-List DisplayName, DisplayValue, ValidDisplayValues

Set-NetAdapterAdvancedProperty -Name "NIC1","NIC2","NIC3","NIC4" -RegistryKeyword "*JumboPacket" -RegistryValue 9014
```

## 6. SET switch on NIC1 + NIC2

```powershell
New-VMSwitch -Name $Switch -NetAdapterName "NIC1","NIC2" -EnableEmbeddedTeaming $true -AllowManagementOS $false -MinimumBandwidthMode Weight
Set-VMSwitchTeam -Name $Switch -LoadBalancingAlgorithm HyperVPort
Set-VMSwitch -Name $Switch -DefaultFlowMinimumBandwidthWeight 50

# Host virtual NICs
Add-VMNetworkAdapter -ManagementOS -SwitchName $Switch -Name "Management"
Add-VMNetworkAdapter -ManagementOS -SwitchName $Switch -Name "LiveMigration"

Set-VMNetworkAdapterVlan -ManagementOS -VMNetworkAdapterName "Management"    -Access -VlanId 100
Set-VMNetworkAdapterVlan -ManagementOS -VMNetworkAdapterName "LiveMigration" -Access -VlanId 101

Set-VMNetworkAdapter -ManagementOS -Name "Management"    -MinimumBandwidthWeight 10
Set-VMNetworkAdapter -ManagementOS -Name "LiveMigration" -MinimumBandwidthWeight 30

# IPs
New-NetIPAddress -InterfaceAlias "vEthernet (Management)" -IPAddress $MgmtIP -PrefixLength 24 -DefaultGateway $Gateway
Set-DnsClientServerAddress -InterfaceAlias "vEthernet (Management)" -ServerAddresses $DnsSrv

New-NetIPAddress -InterfaceAlias "vEthernet (LiveMigration)" -IPAddress $LMIP -PrefixLength 24
Set-DnsClient -InterfaceAlias "vEthernet (LiveMigration)" -RegisterThisConnectionsAddress $false
Set-NetAdapterAdvancedProperty -Name "vEthernet (LiveMigration)" -RegistryKeyword "*JumboPacket" -RegistryValue 9014
```

**Why it's built exactly like this:**
- Both NICs carry traffic, so losing one cable or switch doesn't disconnect the host or its VMs.
- The switch name, uplink mode (Embedded Team), load balancing (Hyper-V Port) and bandwidth mode (Weight) match the VMM logical switch built in 6.4. VMM can then **convert** it in place, without recreating it (0.1 D1). **Don't change these values.**
- The same switch name exists on all 4 hosts, so DC/SQL/VMM VMs can run on and live-migrate to any host.

## 7. Storage NICs (NIC3 / NIC4)

```powershell
New-NetIPAddress -InterfaceAlias "NIC3" -IPAddress $iSCSIA_IP -PrefixLength 24
New-NetIPAddress -InterfaceAlias "NIC4" -IPAddress $iSCSIB_IP -PrefixLength 24

foreach ($n in "NIC3","NIC4") {
    Set-DnsClient -InterfaceAlias $n -RegisterThisConnectionsAddress $false
    Disable-NetAdapterBinding -Name $n -ComponentID ms_msclient, ms_server   # no SMB client/server on storage NICs
}
```

Expected:
- `EmbeddedTeamingEnabled = True`, `BandwidthReservationMode = Weight`, `IovEnabled = False`.
- Management VLAN 100, LiveMigration VLAN 101.
- Gateway reachable. The jumbo ping works between hosts on VLAN 101.
