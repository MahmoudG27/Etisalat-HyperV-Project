## 3. Jumbo frames (required)

| Where | MTU |
|---|---|
| NIC1/NIC2 server ports (trunk) | **9216** (or switch maximum) |
| NIC3/NIC4 server ports (iSCSI) | **9216** |
| Links between switches (peer link / ISL / uplinks) carrying these VLANs | **9216** |
| Any L3 interface / SVI / router hop that carries the **HNV-PA** VLAN | **9216** |
| SAN iSCSI ports | **9000** |

**Why:** SDN encapsulates customer traffic in VXLAN on the HNV-PA network, which adds ~50+ bytes per packet. Microsoft's minimum on the PA path is **1674**.
A **single** hop left at 1500 silently drops large packets, while small pings still work, so the problem shows up later as "some applications hang".
Customer VMs stay at MTU 1500. On our side, the hosts are set to 9014 and verified with `ping -f -l 8972`.
