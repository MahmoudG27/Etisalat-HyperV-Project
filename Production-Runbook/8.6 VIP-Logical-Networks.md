# 8.6 VIP logical networks: PrivateVIP, PublicVIP, GREVIP

> Sources:
> - VMM 2025 "Set up an SDN Software Load Balancer" (private/public VIP networks)
> - VMM 2025 "Set up an SDN RAS Gateway" (GRE VIP network)
>
> All three are NC-managed and allocate VIPs only through the Network Controller. No VLAN, no physical switch config: the VIPs are **advertised by BGP** from the MUX/GW (8.7/8.8).

## 1. Values (placeholders from 0.2 §6)

| Network | Prefix | Pool range | Notes |
|---|---|---|---|
| PrivateVIP | `<private-vip-prefix>` (e.g. 10.10.210.0/24) | `.2`–`.254` | SLB Manager VIP comes from here (8.7) |
| PublicVIP | `<public-vip-prefix>` (e.g. 203.0.113.0/24, sized from today's NSX public IPs) | `.2`–`.254` | Customer public IPs, GW IPsec public IP (8.8) |
| GREVIP | `<gre-vip-prefix>` (e.g. 10.10.220.0/27) | `.2`–`.30` | One VIP per GW for GRE (8.8) |

Microsoft rules:
- **Don't use the first IP of the subnet:** VIP pools start at `.2` (L15).
- **Max 1024 addresses per VIP range.**
- In **"IP addresses reserved for load balancer VIPs"**, enter the **same** range as start/end.
- **No gateway / DNS / WINS** on VIP pools.
- The **Gateway public IPv4 address** must **not** be one of the **first three** IPs of the public range (8.8).

## Gate 8.6

> Record the results in 0.3 As-Built-Record.

```powershell
# MGMT01 (VMM PowerShell)
"PrivateVIP","PublicVIP","GREVIP" | ForEach-Object { Get-SCLogicalNetwork -Name $_ } |
    Format-List Name, *NetworkController*, *Public*            # property names vary by VMM build: check NC-managed + public flags
Get-SCStaticIPAddressPool | Where-Object Name -in "IPP-PrivateVIP","IPP-PublicVIP","IPP-GREVIP" |
    Format-List Name, Subnet, IPAddressRangeStart, IPAddressRangeEnd, *VIP*
```

- The three logical networks exist and are NC-managed. `PublicVIP` is flagged **Public IP address network**.
- Every pool starts at `.2` or later, its VIP reservation equals its range, and it has no gateway.
- The SLBM VIP, GW public IPv4 and test VIP are chosen and recorded in 0.3 §11.
