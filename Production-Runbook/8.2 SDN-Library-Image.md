# 8.2 SDN library image `WS2025-DC-SDN.vhdx`

> One generalized image for NC, MUX and GW, built from the golden image `WS2025-DC-DE.vhdx` (1.2).
> It prevents lab problems:
> - **L3:** the VMM Guest Agent needs Visual C++ x64. Without it, every deployment ends in error 22655.
> - **L5:** RSAT-AD-PowerShell must be present.
> - **L7:** never copy the disk before Sysprep has finished.

## 1. Temporary build VM

```powershell
# HV01 (or the node that owns the VM)
. C:\ClusterStorage\CSV01\_Base\Build\New-InfraVM.ps1
$csv = "C:\ClusterStorage\CSV01"
New-InfraVM -Name SDN-IMG -vCPU 2 -RAM 4GB -OSDiskSize 60GB -Path "$csv\_Build" -BaseVhdx "$csv\_Base\WS2025-DC-DE.vhdx" -Vlan 100
Start-VM SDN-IMG
$local = Get-Credential -UserName "Administrator" -Message "Local admin password from 1.2"
Wait-VMReady -Name SDN-IMG -Credential $local
```

**Don't join the domain.** Give it a temporary IP only so Windows Update works:

```powershell
# HV01
Invoke-Command -VMName SDN-IMG -Credential $local -ScriptBlock {
    $nic = (Get-NetAdapter | Select-Object -First 1).Name
    New-NetIPAddress -InterfaceAlias $nic -IPAddress 10.10.100.49 -PrefixLength 24 -DefaultGateway 10.10.100.1
    Set-DnsClientServerAddress -InterfaceAlias $nic -ServerAddresses 10.10.100.21, 10.10.100.22
    # only if a proxy is used (0.2 §1 #17b) – the VM isn't in the domain, so the GPO doesn't apply:
    # netsh winhttp set proxy proxy-server="<proxy>:<port>" bypass-list="*.etisalat.local;10.10.*;<local>"
}
```

## 3. Visual C++ x64 (L3) and RSAT-AD-PowerShell (L5)

Use the VC++ package that ships with **VMM** itself, so the version matches the Guest Agent:

```powershell
# MGMT01 – find the files on VMM01 (exact subfolder depends on the VMM build/UR)
Get-ChildItem "\\VMM01\C$\Program Files\Microsoft System Center\Virtual Machine Manager\agents" -Recurse -Include vcredist_x64.exe, vmmGuestAgent.msi |
    Select-Object FullName, LastWriteTime
```

```powershell
# HV01 – copy vcredist_x64.exe into the VM and install it silently
Copy-Item "\\VMM01\C$\Program Files\Microsoft System Center\Virtual Machine Manager\agents\<path from above>\vcredist_x64.exe" C:\Temp\ -Force
Copy-VMFile -Name SDN-IMG -SourcePath C:\Temp\vcredist_x64.exe -DestinationPath C:\Install\vcredist_x64.exe -FileSource Host -CreateFullPath

Invoke-Command -VMName SDN-IMG -Credential $local -ScriptBlock {
    Start-Process C:\Install\vcredist_x64.exe -ArgumentList "/install /quiet /norestart" -Wait
    Install-WindowsFeature RSAT-AD-PowerShell
    Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*, HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* |
        Where-Object DisplayName -like "*Visual C++*x64*" | Select-Object DisplayName, DisplayVersion
    Get-WindowsFeature RSAT-AD-PowerShell | Select-Object Name, InstallState
}
```

If `vcredist_x64.exe` isn't in the agents folder of your VMM build, use the current **Microsoft Visual C++ Redistributable (x64)** from Microsoft's official download page. Exact version: *to be verified* against the Guest Agent's requirement.

## 4. Clean up and generalize (L7)

```powershell
# HV01
Invoke-Command -VMName SDN-IMG -Credential $local -ScriptBlock {
    # Remove the 1.2 answer file: VMM injects its own (computer name, domain join, AVMA key)
    Remove-Item C:\Windows\Panther\unattend.xml -Force -ErrorAction SilentlyContinue
    netsh winhttp reset proxy
    $nic = (Get-NetAdapter | Select-Object -First 1).Name
    Get-NetIPAddress -InterfaceAlias $nic -AddressFamily IPv4 | Remove-NetIPAddress -Confirm:$false
    Remove-Item C:\Install -Recurse -Force -ErrorAction SilentlyContinue
    Start-Process C:\Windows\System32\Sysprep\sysprep.exe -ArgumentList "/generalize /oobe /shutdown /mode:vm"
}

# Wait until the VM is OFF (Sysprep shuts it down itself)
while ((Get-VM SDN-IMG).State -ne 'Off') { Start-Sleep 20 }
```

Check that Sysprep really finished **before** copying (L7):

```powershell
# HV01
$vhd = "C:\ClusterStorage\CSV01\_Build\SDN-IMG\Virtual Hard Disks\SDN-IMG-OS.vhdx"
$m = Mount-VHD -Path $vhd -ReadOnly -Passthru | Get-Disk | Get-Partition | Where-Object DriveLetter
$tag = Get-ChildItem "$($m.DriveLetter):\Windows\System32\Sysprep\Sysprep_succeeded.tag" -ErrorAction SilentlyContinue
Dismount-VHD -Path $vhd
if (-not $tag) { throw "Sysprep_succeeded.tag missing - do NOT copy this disk" }

Copy-Item $vhd "\\VMM01\MSSCVMMLibrary\VHDs\WS2025-DC-SDN.vhdx"
Remove-VM SDN-IMG -Force
Remove-Item "C:\ClusterStorage\CSV01\_Build\SDN-IMG" -Recurse -Force
```

## 6. Test deployment from VMM (then delete)

VMM console → **Create Virtual Machine** → from `WS2025-DC-SDN.vhdx` → Gen 2, 2 vCPU / 4 GB → network `Management` (static from `IPP-Management`) → guest OS:
- **Workgroup** (joins nothing).
- Product key = WS2025 Datacenter AVMA key `YQB4H-NKHHJ-Q6K4R-4VMY6-VCH67`.
- Admin password from the vault.

Name it `SDN-TEST`, deploy to any host.

```powershell
# HV0x (the host running SDN-TEST)
$c = Get-Credential "Administrator"
Invoke-Command -VMName SDN-TEST -Credential $c -ScriptBlock {
    (Get-CimInstance Win32_ComputerSystem).PartOfDomain                                   # False
    Get-WindowsFeature RSAT-AD-PowerShell | Select-Object InstallState                   # Installed
    Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\* | Where-Object DisplayName -like "*Visual C++*x64*" | Select-Object DisplayName
    Get-Service ScvmmGuestServiceV10 -ErrorAction SilentlyContinue | Select-Object Name, Status    # present if VMM installed the guest agent
    (cscript //nologo C:\Windows\System32\slmgr.vbs /dli) -match "License Status"       # Licensed (AVMA)
}
```

Delete `SDN-TEST` in VMM afterwards (VMs and Services → right-click → Delete).
