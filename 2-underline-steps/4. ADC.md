## Forth Step on one of the Hyper-V server to host ADC:
6) Create DC02 (Windows Server Standard with Desktop Experience) as Additional domain service on the local storage on any server ex: HV02

```powershell
New-VM -Name "DC02" -Generation 2 -MemoryStartupBytes 4GB -NewVHDPath "D:\VMs\DC02\DC02.vhdx" -NewVHDSizeBytes 80GB -SwitchName "Management-vSwitch"
Set-VMProcessor DC02 -Count 2
Set-VMMemory -VMName "DC02" -DynamicMemoryEnabled $false -StartupBytes 4GB
Add-VMDvdDrive -VMName "DC02" -Path "C:\ISO\WindowsServer2025.iso"

$DVD = Get-VMDvdDrive -VMName "DC02"
Set-VMFirmware -VMName "DC02" -FirstBootDevice $DVD

Start-VM DC02
```

## Inside DC02:

**Get the name of the NIC**
```powershell
Get-NetAdapter
```

**Computer Name + DNS + Manual IP**
```powershell
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.100.101 -PrefixLength 24 -DefaultGateway 192.168.100.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.100.100
Test-NetConnection 8.8.8.8
Rename-Computer -NewName DC02 -Restart
```

**Install AD Role and build Domain**
```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSDomainController -DomainName "etisalat.local" -InstallDns -Credential (Get-Credential)
```

```powershell

```
# To transfer all five roles only to DC02:
