# First these steps. you should configure the SAN itself. create target and add the 4 servers IQN to let them in Access List.

# Connect Servers with SAN:
# ON all Servers:
```powershell
# IP of SAN server
New-IscsiTargetPortal -TargetPortalAddress "192.168.100.150"

# Show available Targets 
Get-IscsiTarget

# Add permanent connection with SAN
Connect-IscsiTarget -NodeAddress "://1991-5.com.microsoft:san-target-01" -IsPersistent $true -IsMultipathEnabled $true
```

# On only single server ex: HV01
```powershell
# review the new disks
Get-Disk

# prepare Quoram disk (assume number is 2 in menu)
Initialize-Disk -Number 2 -PartitionStyle GPT
New-Partition -DiskNumber 2 -UseMaximumSize -AssignDriveLetter | Format-Volume -FileSystem NTFS -NewFileSystemLabel "Quorum"

# prepare Data disk (assume number is 3 in menu)
Initialize-Disk -Number 3 -PartitionStyle GPT
New-Partition -DiskNumber 3 -UseMaximumSize -AssignDriveLetter | Format-Volume -FileSystem ReFS -NewFileSystemLabel "VM-Storage"
```

# To Scan the reset servers HV02, HV03, HV04 and show disks online
```powershell
Update-StorageProviderCache
Get-Disk | Where-Object IsOffline -eq $true | Set-Disk -IsOffline $false
```

# On only single server HV01
# Check and build Failover Cluster
```powershell
Test-Cluster -Node "HV01","HV02","HV03","HV04"

# If check command success run the below command to create the cluster. Give the cluster Name and Static IP to manage the cluster itself.
New-Cluster -Name "New-Production-Cluster" -Node "HV01","HV02","HV03","HV04" -StaticAddress "192.168.100.200"
```

# On only single server HV01
# After cluster created it will pull target Disks from SAN and put it into Cluster Pool as "Available Storage". Then we will convert Data Disk to "CSV" to be a shared path between the four servers and can any server read/write on it

```powershell
# Show disks inside Cluster
Get-ClusterResource | Where-Object ResourceType -eq "Physical Disk"

# Convert Data Disk 
Add-ClusterSharedVolume -Name "Cluster Disk 2"
```
