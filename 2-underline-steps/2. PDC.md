## Second Step on one of the Hyper-V server to host PDC:

# Create DC01 (Windows Server Standard with Desktop Experience) as VM on the local storage on any server ex: HV01
```powershell
New-VM -Name "DC01" -Generation 2 -MemoryStartupBytes 4GB -NewVHDPath "D:\VMs\DC01\DC01.vhdx" -NewVHDSizeBytes 80GB -SwitchName "Management-vSwitch"
Set-VMProcessor DC01 -Count 2
Set-VMMemory -VMName "DC01" -DynamicMemoryEnabled $false -StartupBytes 4GB
Add-VMDvdDrive -VMName "DC01" -Path "C:\ISO\WindowsServer2025.iso"

$DVD = Get-VMDvdDrive -VMName "DC01"
Set-VMFirmware -VMName "DC01" -FirstBootDevice $DVD

Start-VM DC01
```

## Inside DC01:

**Get the name of the NIC**
```powershell
Get-NetAdapter
```

**Computer Name + DNS + Manual IP**
```powershell
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.100.100 -PrefixLength 24 -DefaultGateway 192.168.100.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.100.100
Test-NetConnection 8.8.8.8
Rename-Computer -NewName DC01 -Restart
```

**Install AD Role and build Domain**
```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName etisalat.local -DomainNetbiosName ETISALAT -InstallDns -Force
```
# Will ask for **Safe Mode password** so you need to decide it before, then the VM will restart and take some time

# After Restarting let the DNS forward to internet.
# Sign in with ETISALAT\Administrator and the password.
```powershell
Add-DnsServerForwarder -IPAddress 8.8.8.8
Resolve-DnsName microsoft.com
```
