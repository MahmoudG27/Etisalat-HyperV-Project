## First Step on any phsical Server:

1) Install Windows Server 2025 Core on the 4 physical servers.

2) Set Manual IP, adjust time & time zone and Change Computer Name.
```powershell
Set-TimeZone -Id "Egypt Standard Time"

# Check the name of the NIC
Get-NetAdaptor
# Set the manual IP, Gateway and DNS - Should chane NIC name.
New-NetIPAddress -InterfaceAlias "Ethernet0" -IPAddress 192.168.10.11 -PrefixLength 24 -DefaultGateway 192.168.10.1

Rename-Computer -NewName "HV01" -Force

Restart-Computer
```

3) On every Server install Hyper-V Role and Failover Clustering and MIPO Features
```powershell
Install-WindowsFeature -Name Hyper-V -IncludeManagementTools
Install-WindowsFeature -Name Failover-Clustering -IncludeManagementTools
Install-WindowsFeature -Name Multipath-IO -IncludeManagementTools
Restart-Computer
```
# Checking install feature success
```powershell
Get-WindowsFeature -Name Hyper-V, Failover-Clustering, Multipath-IO
```

4) Install and Definitions Required management tools like network cards, HBA or iSCSI, and MPIO, depending on the storage.
# Multipath I/O (MPIO): Important feature needs to install. it make sure doesn't disconnected with SAN if any cable or port disable because it provide more than path to connect same disk storage on SAN
# ISCSI Initiator Client: doesn't need to implement it. but should enable the service and works automatically. 

# Enable iSCSI
```powershell
Set-Service -Name MSiSCSI -StartupType Automatic
Start-Service -Name MSiSCSI
```

# Adjust MPIO feature to recognizes the iSCSI Disks.
```powershell
Enable-MSDSMAutomaticClaim -BusType iSCSI
Restart-Computer
```

# On the four physical server to create Management vSwitch
```powershell
Get-NetAdapter
```
```powershell
New-VMSwitch -Name "Management-vSwitch" -NetAdapterName "Ethernet0" -AllowManagementOS $true
```

5) Before creating a cluster, you must ensure that the hardware, firmware, network adapters, and storage multipathing are compatible.
